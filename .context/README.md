# Context Directory

This directory contains Context Compaction Continuity (CCC) files for maintaining
session continuity across long development sessions.

## Structure

```
.context/
├── README.md           # This file
├── sessions/           # Session continuation files
│   └── session_YYYY-MM-DD_description.ccc.md
├── checkpoints/        # Auto-generated checkpoints
│   └── checkpoint_YYYY-MM-DD-trigger.md
└── runtime/            # Volatile state, regenerated each session (gitignored)
    └── context.md
```

## Session Files

Session files are created when:
- Token usage reaches threshold (150k+)
- End of major milestone
- Before complex refactor
- User explicitly requests via `dk_end_session`

## Checkpoint Files

Checkpoints are auto-generated:
- At 95% context usage (PreCompact hook)
- Manual request via `dk_create_checkpoint`
- End of day/week triggers

## Usage

**Resuming a session:**
Reference a session file to restore context:
- "Continue from session_2025-11-25_bootstrap.ccc.md"
- "Resume where we left off"
